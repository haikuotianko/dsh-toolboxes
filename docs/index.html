让 AI 直接调用 ffmpeg、ripgrep、jq…

一个 MCP 服务器 + 一个管理页：按当前系统下载命令行工具、登记成 AI 能直接调用的工具， 并把“它正在跑什么、跑到哪、多快”实时显示出来。转码、抽帧、批量改名、搜代码、下载媒体， 不用再让 AI 现场写脚本。

为什么不是“让 AI 写个脚本”

脚本每次都要重写、每次都可能踩同一个坑；工具箱把工具、安装和运行记录一次性解决。

📦

一条命令装好

ffmpeg / ripgrep / fd / jq / yt-dlp 按系统自动挑包，多源失败自动重试，装完直接可调用。

所有正在执行的命令集中列出，带工具、参数、耗时；随时展开控制台或一键取消（连子进程）。

先查版本再写脚本

安装

选一种就行。装好的可执行文件叫 toolbox（Windows 是 toolbox.exe）。

# 1. 下载并解压到任意目录，例如 D:\tools\toolbox
#    https://github.com/haikuotianko/dsh-toolboxes/releases/download/v0.3.0/toolbox-windows-amd64.zip
# 2. 把该目录加进 PATH，然后：
toolbox -version
toolbox -ui        # 打开管理页

# 3. 注册到你的 MCP 客户端（管理页里「接入 AI」可一键生成）
toolbox -setup -patch "<profile>\node_modules\dsh-toolboxes\cordis.patch.yml"
# Apple Silicon 用 toolbox-darwin-arm64.zip，Intel 用 toolbox-darwin-amd64.zip
curl -L -o tb.zip https://github.com/haikuotianko/dsh-toolboxes/releases/download/v0.3.0/toolbox-darwin-arm64.zip
unzip -o tb.zip -d ~/bin && chmod +x ~/bin/toolbox
# macOS 首次运行若被 Gatekeeper 拦：系统设置 → 隐私与安全性 → 仍要打开
~/bin/toolbox -version
# amd64 / arm64 按机器选
curl -L -o tb.zip https://github.com/haikuotianko/dsh-toolboxes/releases/download/v0.3.0/toolbox-linux-amd64.zip
unzip -o tb.zip -d ~/.local/bin && chmod +x ~/.local/bin/toolbox
~/.local/bin/toolbox -version
dsh plugin --profile <profile> add dsh-toolboxes

# 插件首次启用时会按平台下载 Release 里的二进制，校验 SHA256SUMS 后缓存到
#   <toolbox root>\bin\toolbox-v0.3.0.exe
# 想用自己构建的二进制：设置 TOOLBOX_BIN 指向它
go install github.com/haikuotianko/dsh-toolboxes@latest

# 模块名决定产物名字，装出来叫 dsh-toolboxes；想用文档里的 toolbox 就重命名
mv "$(go env GOPATH)/bin/dsh-toolboxes" "$(go env GOPATH)/bin/toolbox"

接给 AI 用

管理页能跑，不等于 AI 能用。下面任意一份配置加到你的 MCP 客户端即可。

// Claude Code / Claude Desktop（claude_desktop_config.json）
{
  "mcpServers": {
    "toolbox": { "command": "toolbox", "args": ["-mcp"] }
  }
}

// opencode（opencode.json）
{
  "mcp": {
    "toolbox": { "type": "local", "command": ["toolbox", "-mcp"], "enabled": true }
  }
}

DeepSeek Harness 用户：打开管理页 →「接入 AI（MCP）」，点「复制配置」即可拿到带本机真实路径的版本； 或用 toolbox -setup -patch <profile>/node_modules/dsh-toolboxes/cordis.patch.yml 一次写好。

安全边界（请先读）

这个工具会下载并执行程序

  • 它按目录里的 URL 下载可执行文件、解包、直接运行，不经过任何沙箱，权限等于运行它的用户。
  • 目录条目写了 sha256 才会校验；没写时，信任完全建立在 URL 上。企业环境建议自建镜像并补校验和。
  • 内置目录里个别下载源走了第三方 GitHub 镜像；介意的话在 <root>/catalog.json 覆盖成官方地址。
  • 管理页只监听回环地址（127.0.0.1），不提供远程访问，不要反代到公网。

漏洞报告方式见 SECURITY.md。
